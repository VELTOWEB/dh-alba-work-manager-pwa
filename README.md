# 알바기록 PWA

개인용 알바 근무·급여 관리 앱입니다.

## 실행
정적 서버에서 프로젝트 폴더를 실행하세요.

- VS Code Live Server 권장
- 또는 `python -m http.server 8000`
- 브라우저에서 `http://localhost:8000` 접속

PWA 설치와 서비스 워커는 `file://`이 아니라 HTTP/HTTPS 환경에서 동작합니다.

## 핵심 기능
- 근무지 여러 개 등록 및 기본 시급/급여일 저장
- 근무 일정 및 반복 일정 등록
- 출근/퇴근 원터치 기록
- 예정 없이 출근
- 휴게시간, 근무시간, 예상 급여 자동 계산
- 기록 수정/삭제
- 월간 캘린더
- 월별 통계, 목표 수입, 최근 6개월 그래프
- 실제 급여 입력 및 예상 금액 비교
- IndexedDB 영구 저장
- JSON 백업/복원
- PWA / 오프라인 기본 실행


## v2 버튼 수정
- index.html에 핵심 CSS/JavaScript를 내장해 외부 스크립트 로딩이 막혀도 버튼이 동작하도록 수정했습니다.
- 동적 버튼은 전역 이벤트 위임 방식으로 처리합니다.
- IndexedDB가 제한되는 환경에서는 localStorage/메모리 호환 저장 모드로 자동 전환합니다.
- Service Worker 캐시를 v2로 갱신해 이전 app.js가 남는 문제를 줄였습니다.

## v3 클릭 오류 핵심 수정
- 앱 시작 시 `monthKey()`가 아직 초기화되지 않은 `pad` 함수를 먼저 참조해 JavaScript가 즉시 중단되던 문제를 수정했습니다.
- `pad`를 함수 선언으로 변경해 초기 로딩 단계에서 안전하게 호출되도록 수정했습니다.
- 실제 브라우저 DOM에서 첫 근무지 등록, 일정 추가, 출근, 하단 메뉴 전환까지 클릭 흐름을 검증했습니다.
- Service Worker 캐시를 v3로 갱신했습니다.

## v4 디자인 변경
- 전체 테마를 화이트 + 연핑크로 변경
- 메인 버튼, 카드 강조, 캘린더, 통계 그래프, 하단 메뉴를 핑크 계열로 통일
- 가독성을 위해 본문 텍스트는 진한 로즈 그레이 유지
- PWA 아이콘과 theme color도 연핑크로 변경
- 기존 기능 및 데이터 구조는 유지
